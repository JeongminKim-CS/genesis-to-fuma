# GENESIS to FUMA

An R-based automation tool for converting GENESIS GWAS score test results into
FUMA SNP2GENE-compatible input files.

## Overview

This project automates the preparation of GWAS summary statistics generated by
GENESIS for downstream analysis using FUMA.

The script processes multiple GENESIS CSV files, applies a configurable P-value
threshold, selects and renames the required columns, and exports tab-delimited
TXT files.

## Features

- Automatically discovers multiple GENESIS CSV files.
- Processes each dataset independently.
- Applies a configurable P-value threshold.
- Converts GENESIS columns to the FUMA GRCh38 input format.
- Generates descriptive output filenames automatically.
- Validates generated TXT files.
- Supports batch processing without manually selecting individual files.

## Requirements

- R (base R functions)
- GENESIS score test results in CSV format
- Genomic coordinates based on GRCh38

## Input Data

Place GENESIS CSV files directly inside `03_data/`.

Example:

```text
03_data/
├── G001_delta_genesis.csv
├── G002_delta_genesis.csv
└── G003_delta_genesis.csv
```

Required input columns:

- `CHR`
- `POS`
- `EFFECT_ALLELE`
- `OTHER_ALLELE`
- `BETA`
- `PVAL`


## Usage

1. Open the RStudio project.
2. Place GENESIS CSV files in `03_data/`.
3. Set the desired P-value threshold in the R script.

```r
p_threshold <- 1e-3
```

4. Run the script from the project root directory.

```r
source("01_r/prepare_snp2gene.R")
```

5. Find the generated files in `02_output/snp2gene/`.

## Example Data

Synthetic GENESIS datasets are provided in the `examples/`
directory for testing purposes.

The examples contain fictional SNP data and do not represent
real GWAS findings or validated genomic coordinates.

### Running the Example

1. Copy the CSV files from `examples/` into `03_data/`.
2. Set the P-value threshold to `1e-3`.
3. Run the conversion script:

```r
source("01_r/prepare_snp2gene.R")
```

4. Check the generated TXT files in `02_output/snp2gene/`.

Each example dataset contains six SNP records. Three records
pass the P-value threshold of `1e-3`.

The expected result is three TXT files, each containing
three SNP records.

All three example datasets passed local validation.

## Output Format

Each CSV file is converted into an individual tab-delimited TXT file
containing six columns:

```text
chromosome
base_pair_location
effect_allele
other_allele
beta
p_value
```

Example output filename:

```text
G001_delta_FUMA_snp2gene_p1e-3_GRCh38.txt
```

## Validation

The current validation checks:

- Output file existence
- Required output column names and order
- Non-empty output data
- Missing values
- P-value range and configured threshold

These checks do not independently verify genomic coordinates or complete data
integrity.

## Current Status

The automated CSV-to-TXT conversion workflow has been
implemented and tested locally with three GENESIS datasets.

All three datasets passed the implemented local validation
checks.

**FUMA server-side validation and downstream SNP2GENE
analysis have not yet been completed.**

## Limitations

- Input coordinates must use GRCh38.
- Input CSV files must contain the required GENESIS columns.
- The current script searches CSV files directly within `03_data/`.
- Input files already filtered by P-value cannot recover
  previously excluded SNPs.
- Pre-filtered summary statistics are not equivalent to complete
  genome-wide summary statistics for downstream analyses that
  require full data.
